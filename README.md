# 💗 Нежное поздравление для мамы

Интерактивный одностраничный сайт-подарок: альбом воспоминаний, романтичное письмо и финальный сюрприз для самого дорогого человека.

## ✨ Возможности

- **Стартовый экран-приглашение** — сайт открывается как личная открытка с красивой заставкой.
- **Фоновая музыка** — трек запускается после первого действия посетителя и может включаться или выключаться кнопкой.
- **Карусель фотографий** — 12 воспоминаний оформлены в виде полароидов.
- **Управление с компьютера и телефона** — работают стрелки, а на смартфонах можно листать фотографии свайпами.
- **Анимированное письмо** — текст появляется эффектом печатной машинки.
- **Атмосфера праздника** — движущиеся сердечки, мягкие анимации и мерцающий след курсора.
- **Финальный сюрприз** — кнопка запускает поздравление и конфетти с разных сторон экрана.
- **Адаптивный дизайн** — удобно просматривается как на смартфоне, так и на компьютере.
- **Отзывчивые анимации** — поддерживается режим уменьшенного движения системными настройками.

## 🖼️ Как устроен сайт

Сайт состоит из четырёх последовательных сцен:

1. **Обложка** — приветствие и кнопка «Открыть альбом».
2. **Фотоальбом** — история семьи в фотографиях и подписи к каждому кадру.
3. **Письмо** — личное текстовое поздравление с эффектом постепенного появления.
4. **Финал** — большая фраза любви и праздничное конфетти.

## 🛠️ Технологии

- HTML5
- CSS3
- JavaScript без сборки и фреймворков
- GSAP — анимации интерфейса
- canvas-confetti — финальный эффект конфетти
- Google Fonts — шрифты Comfortaa, Caveat и Playfair Display

## 🌐 Совместимость

Сайт предназначен для современных версий Chrome, Firefox, Edge и Safari. Для работы анимаций и эффектов нужен доступ к интернету для загрузки GSAP, canvas-confetti и шрифтов Google Fonts; их можно заменить локальными аналогами для полностью автономной версии.
